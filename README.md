# Артефакты проекта CooBee (3 семестр)

В этой папке собраны материалы ML-исследования архитектуры Structured Harness для рекомендаций подарков.

## 1. Данные для эксперимента
- catalog_research_v4.csv — каталог из 80 товаров с 29 атрибутами (цены, теги, рейтинги, профессии).
- golden_set.csv — тестовый набор из 32 запросов с ручной разметкой (оценки релевантности 2/1/0).

## 2. Методология и результаты
- experiment_protocol.md — полный протокол эксперимента (гипотеза, Ablation Study, метрики NDCG, Bootstrap CI).
- results_summary.md — краткая сводная таблица результатов (B0, B1, H1–H6).

## 3. Исходный код (если загружали)
- auto_save_results.py — код запуска конфигураций Harness.
- final_analysis.py — скрипт подсчета метрик и стратификации.
